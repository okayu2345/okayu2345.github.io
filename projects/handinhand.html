PROJECT / Unity / 2D

HandinHand

「つかむ」をテーマに、2人で協力してステージを攻略する2Dアクションゲーム。企画・開発とデザイナー4名への依頼・管理を担当。

Tokyo Game Show 2025 展示

開発情報

使用技術
Unity / 2D
制作期間
2025/8/1〜9/28（約2か月）
イベント・支援
Tokyo Game Show 2025 / IGDA日本スカラーシップ
担当
リーダー / リードプログラマー / プランナー

ゲームの特徴

物をつかむアクションをテーマにした、2人協力型の2Dアクションゲームです。2人で協力しながら、ステージに用意された仕掛けを攻略していきます。

企画・開発とチームづくり

ゲーム制作仲間を募る掲示板で自身の企画を公開し、協力してくれるデザイナーを募集しました。参加してくださった4名のデザイナーに、それぞれ制作を依頼し、作業を管理しました。自身はリーダー・リードプログラマー・プランナーとして制作を進めました。

選出・展示

完成間近の作品でIGDA日本のスカラーシップに応募し、選出されました。Tokyo Game Show 2025で作品を展示しました。
